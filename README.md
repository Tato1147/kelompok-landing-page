# Landing Page

A comprehensive landing page application that serves as a central hub for accessing various aplications. This platform aims to improve accessibility of village services through modern web technologies.

## Features

### Home Page
- Hero section with village introduction
- Six service sections with detailed descriptions
- Direct links to all applications

### Authentication System
- **User Registration**: Create account with username, email, and password
- **Secure Login**: JWT-based authentication
- **Password Security**: Bcrypt hashing with salt rounds
- **Session Management**: Token-based authentication with 1-hour expiration

### Information Pages

#### About Page
- Vision and mission
- Goals and objectives
- Platform features overview

#### Services Page
- Detailed descriptions of all 6 applications:
  1. **Tentang Desa** - Platform profile and information
  2. **Finansial** - Financial transparency and budget tracking
  3. **Infrastruktur** - Infrastructure development monitoring
  4. **UMKM Desa** - Local business promotion platform
  5. **Edukasi** - Educational resources and training
  6. **Acara Desa** - Village events and announcements

#### Reviews Page
- Submit reviews and ratings for applications
- Filter reviews by application
- Sort reviews by rating (highest/lowest)
- View all community feedback
